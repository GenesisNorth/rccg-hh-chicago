## 🛠️ Technology Stack

### Frontend
- **Web**: Next.js 14, TypeScript, Tailwind CSS, shadcn/ui
- **Mobile**: Flutter, Dart, Material Design 3

### Backend
- **Database**: Firebase Firestore
- **Authentication**: Firebase Auth
- **Functions**: Firebase Cloud Functions
- **Storage**: Firebase Storage + Cloudinary
- **Real-time**: Firebase Realtime features

### Integrations
- **Payments**: Paystack (primary), Stripe (secondary)
- **Email**: SendGrid/Mailgun
- **SMS**: Twilio
- **Analytics**: Firebase Analytics + Custom dashboards
- **Monitoring**: Firebase Performance + Sentry

### DevOps
- **Hosting**: Vercel (web), Firebase Hosting (backup)
- **CI/CD**: GitHub Actions
- **Monitoring**: Firebase Performance, Sentry
- **Backup**: Automated Firebase backups
